# Bakery

## Unity UGUI 기반 캐주얼 베이커리 RPG  프로토타입

빵을 만들고 진열하는 운영 화면과, 몬스터를 처치하며 성장하는 전투 스테이지를 구현한 모바일 게임 프로토타입입니다.

현재 혼자 개발하고 있으며, 운영·전투 기능 구현부터 UI 구성, 데이터와 리소스 연결까지 담당하고 있습니다.
AI는 이미지와 테이블 데이터 제작, 코드 수정 및 검증을 보조하는 도구로 활용했습니다.

초기에는 더미 UI와 단색 캐릭터로 기능을 구성했습니다.
이후 캐릭터와 배경을 교체하면서 전투 애니메이션, 공격 방향 처리, 플레이어 추적 화면을 추가했습니다.

### 개발 정보

- 개발 형태 : 개인 개발
- 개발 상태 : 개발 진행 중
- 대상 플랫폼 : 모바일
- 주요 작업 : 운영·전투 기능 구현, UGUI 화면 및 팝업 구성, 데이터·리소스 연동
- 개발 환경 : Unity6, C#, UGUI, Animator/AnimationClip
- 사용 라이브러리 : SuperScroll
- 개발 보조 도구 : Claude, AI 이미지 생성 도구, Unity CLI

### 주요 구현

## 1. 상태머신을 통한 전투 흐름 관리

CharacterStateMachine 에서 전투 시작, 플레이어와 몬스터 생성, 몬스터 리스폰, 스테이지 클리어와 결과 팝업 호출을 처리합니다.

캐릭터의 전투 상태와 애니메이션을 연결하는 부분은 CharacterAnimationBridge로 분리했습니다.
Idle, Attack, Hit 애니메이션 호출을 이 컴포넌트에 모아, 캐릭터 로직에서 Animator를 직접 다루는 부분을 줄였습니다.

몬스터는 오브젝트 풀을 통해 생성·재사용하도록 구성했으며, 이동 경로 탐색에는 A* 알고리즘을 사용했습니다.

## 2. 이동과 공격이 겹칠 때의 방향 처리

이동 방향만으로 캐릭터의 좌우 방향을 결정하면, 이동하면서 공격할 때 공격 대상의 반대쪽을 바라보는 문제가 있었습니다.

이를 해결하기 위해 CharacterFacing 에서 상태에 따라 방향 결정 기준을 나눴습니다.

- 일반 이동 중에는 이동 방향을 기준으로 좌우 방향을 변경합니다.
- 공격 중에는 이동 방향보다 공격 대상의 방향을 우선합니다.

이렇게 처리해 이동 중에도 캐릭터가 공격 대상을 바라보도록 수정했습니다.
방향 전환은 CharacterFacing, 애니메이션 호출은 CharacterAnimationBridge 에서 담당하도록 역할을 나눴습니다.

## 3. 전투 영역과 고정 UI 분리

기존에는 배경, 캐릭터, HUD가 같은 Canvas 구조에 있어 플레이어를 따라 전투 영역만 이동시키기 어려웠습니다.

UGUI 기반의 전투 구조 안에서 배경과 캐릭터를 BattleWorld 아래로 분리하고, 타이머·수집 패널·버튼은 고정 UI로 유지했습니다.
캐릭터도 pageStage.CharacterRoot 를 통해 전투 영역 아래에 생성되도록 변경했습니다.

StageCameraFollow 는 플레이어 위치를 기준으로 BattleWorld 를 부드럽게 이동시킵니다.
실제 Camera 대신 UGUI의 전투 영역을 이동시켜, HUD 위치를 유지하면서 플레이어를 추적하도록 구현했습니다.

## 4. 운영 화면과 팝업 구성

Main, WorldMap, Stage 화면과 제조·진열·시설·레벨업·결과 팝업을 구성했습니다.

빵 제조 목록에는 SuperScroll을 사용했습니다.
UI를 정리하는 과정에서는 ScrollView와 GridLayout의 콘텐츠 위치가 어긋나는 문제를 수정하고, 버튼·패널·텍스트·보상 슬롯의 스타일을 맞췄습니다.

기존 UGUI 프리팹 구조를 유지하면서 운영 화면과 전투 화면에 목재·양피지 톤을 적용했습니다.

## 5. 캐릭터 리소스와 애니메이션 연결

초기의 단색 Image를 제빵사 캐릭터와 꿀 반죽 몬스터 이미지로 교체하고, 전투용 꿀숲 배경을 적용했습니다.

생성 이미지는 Sprite로 임포트해 Player와 Monster 프리팹에 연결했습니다.
이후 AnimatorController와 Idle, Attack, Hit 클립을 구성하고, 전투 상태에 따라 애니메이션이 재생되도록 연결했습니다.

이미지 교체에 필요한 임포트 설정과 프리팹 연결뿐 아니라, 상태에 따른 애니메이션과 좌우 방향 처리까지 함께 적용했습니다.

### AI 활용 

개인 개발 과정에서 필요한 아트 리소스와 데이터 초안을 만들고, 구현을 보조하는 데 AI를 활용했습니다.

| 활용 영역 | 작업 내용 |
| --- | --- |
| 캐릭터·배경 | 제빵사, 꿀 반죽 몬스터, 꿀숲 배경 이미지 제작 |
| 빵 아이콘 | Claude로 프롬프트를 정리한 뒤 나노바나나로 제작 |
| 스킬 이미지 | 레벨업 시 획득하는 스킬 이미지 제작 |
| 테이블 데이터 | Claude를 활용해 빵 제조용 테이블 시트 작성 |
| 개발 보조 | UI 구조 개선, 리소스 연결, 코드 수정 및 Unity CLI를 통한 검증 과정에 활용 |

생성 결과물을 프로젝트에 적용하는 과정에서는 Sprite 설정, 프리팹 참조, Animator 연결, UGUI 배치 등을 조정했습니다.
기존 게임 로직 안에서 리소스가 동작하도록 통합하는 작업도 함께 진행했습니다.

## 코드 하이라이트

### 'StageCameraFollow.cs'

플레이어 위치를 기준으로 전투 월드 레이어만 이동시키는 카메라 추적 로직입니다.
HUD는 고정하고 배경/캐릭터만 움직이도록 'BattleWorld' 구조와 함께 사용합니다.

### 'CharacterFacing.cs'

캐릭터의 기본 방향과 이동 방향을 기준으로 좌우 플립을 처리합니다.
공격 중에는 타겟 방향이 우선되도록 상태머신과 연동했습니다.

### 'CharacterAnimationBridge.cs'

상태머신과 AnimatorController 사이를 연결하는 브릿지 컴포넌트입니다.
'Idle', 'Attack', 'Hit' 애니메이션 호출을 한 곳에 모아 캐릭터 로직을 단순하게 유지했습니다.

### 'CharacterStateMachine.cs'

전투 시작, 플레이어/몬스터 스폰, 몬스터 리스폰, 스테이지 클리어, 결과 팝업 호출을 담당합니다.
'pageStage.CharacterRoot'를 통해 캐릭터가 고정 UI가 아닌 'BattleWorld' 아래 생성되도록 변경했습니다.
